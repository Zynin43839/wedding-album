## สิ่งที่เจอระหว่างทดสอบ (และแก้แล้ว)

### 🔴 อัลบั้มเปิดที่ "รูปเก่าสุด" ไม่ใช่รูปใหม่
R2 เรียง key จากน้อยไปมาก และ id เดิมเริ่มด้วย epoch → หน้าแรกคือรูปแรกของวัน
ในงานจริงแขกจะเปิดมาเจอรูปเช้า และต้องกด "ถัดไป" ~70 ครั้งกว่าจะถึงงานเลี้ยง

**แก้แล้ว**: `makeId()` กลับค่าเวลา (`9999999999999 − now`) → รูปใหม่ = key เล็กสุด = หน้าแรก
และอ่านเวลาจริงจาก `customMetadata.ts` แทนการถอดจาก id

### 🟠 cursor เก่า → 500
แก้แล้ว: ถ้า cursor ใช้ไม่ได้ (error 10023) จะคืนหน้าแรกให้ใหม่แทนการ 500

### 🟠 เขียน id เดียวกันพร้อมกัน → 500
แก้แล้ว: ตอบ **409 conflict** (client retry ได้)

### ✅ Range / วิดีโอบน iPhone
`/i/` เดิมตอบ 200 + ไฟล์เต็มทุกครั้ง — Safari ต้องได้ **206** ถึงจะเล่น/seek ได้
ตอนนี้รองรับแล้ว (ตรวจบน production: `Range: bytes=0-99` → `206`, `bytes 0-99/692`)
